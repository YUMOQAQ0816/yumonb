# 时光小站（Android 本地时间管理）

一个纯本地 Android 原生 Compose 示例工程，底部六个入口依次为：写代码、吃早饭、吃午饭、吃晚饭、首页、我的。

## 在手机上构建
1. 将整个 `LocalTimeManager` 文件夹复制到电脑，使用 Android Studio（建议最新版）打开。
2. 等待 Gradle 同步，安装 Android SDK 35。
3. 连接 Android 手机并开启开发者选项/USB 调试，点击 Run；也可在 Android Studio 的 Build 菜单中生成 APK。

## 已实现
- 编码及三餐计时、结束保存、备注/项目或食物记录、历史卡片。
- 首页搜索、今天/本周/全部筛选、今日编码时长汇总。
- 我的：本周统计、JSON 导入/导出、深浅主题、数据重置、提醒总开关。
- 三餐本地定时提醒（Android 13+ 需允许通知；部分系统需允许闹钟/提醒权限）。
- 记录使用 SharedPreferences 保存在应用私有空间，不申请网络权限，不上传数据。

## 当前版本说明
- 这是可继续扩展的 MVP 工程源码，不是已签名 APK；需要 Android Studio/Android SDK 构建。
- 提醒时间目前按“每天下一次”设置；系统重启后需重新设置提醒。Android 厂商省电策略可能影响准时送达。
- 计时中途切换到其他计时页时，会自动保存前一个计时段。
- 导入 JSON 会替换当前记录，导入前建议先导出备份。
